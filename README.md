# Homebrew Tap

Maintainer-owned Homebrew tap for published formulae.

## Automatic updates

An hourly workflow checks for new [remote-monitor](https://github.com/LMLiam/remote-monitor) releases and opens a pull request that updates `Formula/remote-monitor.rb`. Merge that pull request to ship the new version. The workflow can also be run by hand from the Actions tab as "Update remote-monitor formula".
